# Utility function to insert NA's According to Panel

Utility function to insert NA's According to Panel

## Usage

``` r
annotate_specific_panel(gene_binary, panel_id, samples_in_panel, na_genes, ...)
```

## Arguments

- gene_binary:

  a processed binary matrix

- panel_id:

  name of gene panel

- samples_in_panel:

  samples to be annotated for each panel

- na_genes:

  genes to make NA

- ...:

  other args passed

## Value

an annotated data frame
