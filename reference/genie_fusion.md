# An example GENIE BPC fusions data set

This set was created from a sample of 100 patients from the non-small
cell lung cancer v.2.0-public data set. If a row exists for a given hugo
symbol and tumor-sample-barcode, then the mutation was observed.

## Usage

``` r
genie_fusion
```

## Format

A data frame with fusions retrieved using genieBPC package
