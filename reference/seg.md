# A segmentation file from the cbioPortal datasets

Segmentation file provided by the processing of IMPACT sequencing using
FACETS

## Usage

``` r
seg
```

## Format

A data frame with 30240 observations with 6 variables

- ID:

  Factor, IMPACT sample ID

- chrom:

  chromosome

- loc.start:

  start location

- loc.end:

  end location

- num.mark:

  number of probes or bins covered by the segment

- seg.mean:

  segment mean value, usually in log2 scale
