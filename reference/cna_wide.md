# An example IMPACT cBioPortal CNA in wide format

This set was created from a sample of 20 patients from publicly
available prostate cancer data from cBioPortal
(`study_id = "gbc_mskcc_2022"`).

## Usage

``` r
cna_wide
```

## Format

A data frame with copy number alterations (CNA) retrieved from
cBioPortal.
