# An example of long-format fusion/sv files

This set was created from a sample of 30 patients from publicly
available non-small cell lung cancer data from GENIEBPC
`(cohort = 'NSCLC', version = 'v2.0-public')`

## Usage

``` r
sv_long
```

## Format

A data frame with 30 unique `sample_id` values and 62 hugo symbols
listed
