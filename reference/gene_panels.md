# Public Gene Panels on cBioPortal

Data frame of cBioPortal gene panels sourced from both public and GENIE
cBioPortal instances.

## Usage

``` r
gene_panels
```

## Format

A nested data frame

- gene_panels:

  Gene panel ID

- genes_in_panel:

  List column of Hugo symbols of all genes in each panel

- entrez_ids_in_panel:

  List column of Entrez IDs of all genes in each panel
