# An example data set for an IMPACT analysis coming from a clinical collaborator

This set was created from a sample of 20 patients from publicly
available prostate cancer data from cBioPortal
(`study_id = "gbc_mskcc_2022"`).

## Usage

``` r
clin_collab_df
```

## Format

A data frame with copy number alterations (CNA) retrieved from
cBioPortal.

- `cbioportal_id`:

  character with IMPACT sample ID

- `ctype`:

  character cancer type

- `primary_mets`:

  character with sample type
